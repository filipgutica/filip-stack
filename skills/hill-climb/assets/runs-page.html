Hill Climb Runs

A hill climb improves a pull request that already works, or works toward a goal from scratch. Each round makes a few small edits, and three AI judges compare the result with the version before it without knowing which is new. The edits stay only when most judges prefer them. Some climbs use a score instead, such as an accessibility violation count, or require both.

When the climb ends, the judges compare the version from before the climb with the final version, or the climb compares their scores. That comparison is the verdict below. Select a run to see each round, the votes, and the diff.
