# Know what held a local TCP port

portlog records which process held each local TCP port over time, so you can look back after the process exits.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## What was on port 3000 an hour ago?

```sh
portlog who 3000 --since 2h
```

Show every process recorded on port 3000 in the last two hours, newest first.

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Start the background recorder. |
| `portlog stop` | Stop the recorder. |
| `portlog who 3000` | Show every process that held port 3000, newest first. |
| `portlog free 3000` | Stop the process holding port 3000 now, after confirmation. |

## Keys

| Option | Effect |
| --- | --- |
| `--since 2h` | Limit a `who` query to the last two hours. |
| `-y` | Skip confirmation for `free`. |

## Good to know

**History**  
Recordings stay in `~/.portlog/` for 7 days.

**Command-line arguments**  
portlog never records command-line arguments, because they can hold secrets.

**Recording method**  
On macOS, the recorder polls `lsof` every 2 seconds. On Linux, it reads `/proc/net/tcp`.
