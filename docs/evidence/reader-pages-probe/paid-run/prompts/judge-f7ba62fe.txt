# release-notes

## What it does

Drafts release notes from merged PRs between two tags. It groups PRs by Conventional Commit type, with features, fixes, and breaking changes first.

## When to use it

Use it to gather merged PRs and create a release notes draft. Use `technical-writing` to edit prose.

Run it manually:

```text
/release-notes <from-tag> <to-tag>
```

You must be signed in to `gh`, and both tags must exist.

## How it works

1. Checks authentication. If `gh auth status` fails, it stops.
2. Resolves both tags. If either tag does not exist, it stops before drafting with `TAG_UNRESOLVED`.
3. Gathers merged PRs between the tags and skips PRs labeled `skip-notes`.
4. Groups PRs by type. For PRs with multiple type labels, grouping uses a strict-majority rule. The code breaks ties by label order.
5. Checks breaking changes for a migration line. If the PR body has none, the draft marks it `TODO: migration`.

## What you get

A `RELEASE_NOTES.md` draft in your working tree. The skill writes the file and stops. It never publishes.

# release-notes

## What it does

`release-notes` drafts release notes from PRs merged between two tags.

## When to use it

Use it when you need a release draft gathered from merged PRs. Use `technical-writing` when you need prose edits.

Run it manually with:

```text
/release-notes <from-tag> <to-tag>
```

Illustrative example:

```text
/release-notes v1.0.0 v1.1.0
```

You must be signed in to `gh`, and both tags must exist.

## How it works

The skill checks authentication and the tags before drafting. If `gh auth status` fails or either tag is missing, it stops.

It gathers merged PRs, skips those labeled `skip-notes`, and groups them by Conventional Commit type. Features, fixes, and breaking changes come first.

If more than half of a PR’s type labels name one group, the PR goes there. Ties follow label order.

Each breaking change needs a migration line. If the PR body has none, the draft marks it `TODO: migration`.

## What you get

The skill writes `RELEASE_NOTES.md` in your working tree and stops. It never publishes.
