# See which process held a port

portlog records which process held each local TCP port over time. Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Look up a port

Start the background recorder, then check port 3000:

```sh
portlog start
portlog who 3000
```

The results show every process that held port 3000, newest first.

## Commands

### Limit the history

Show only the last two hours:

```sh
portlog who 3000 --since 2h
```

### Free a port

Stop the process that holds port 3000 now:

```sh
portlog free 3000
```

portlog asks for confirmation before stopping the process. To skip confirmation, use:

```sh
portlog free 3000 -y
```

### Stop recording

Stop the background recorder:

```sh
portlog stop
```

## Good to know

### History

portlog keeps history for 7 days in `~/.portlog/`.

### Command-line arguments

portlog never records command-line arguments because they can hold secrets.
