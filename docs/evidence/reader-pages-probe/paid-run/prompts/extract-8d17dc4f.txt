# Flaky tests and agents

## 1. Understand what a red test prompts

A flaky test fails sometimes without any code change. An agent that sees a red test tries to fix the code, even when the test is flaky. That combination matters when engineers ask agents to work with required test gates.

The agent sees a failure and starts a code fix. But the test can fail while the code stays the same. Before treating that failure as a reason to change code, measure whether the test fails across repeated runs on one commit.

Agents tend to rerun tests until they turn green, or to weaken the assertion. Neither action measures how often the test fails without a code change. A green rerun is one result; the measurement requires counting failures across repeated runs.

A required gate that sometimes fails teaches agents and people to ignore it. The lesson therefore starts with two actions: measure flakiness, then give known-flaky tests an owner and a date while they are fixed.

## 2. Measure flakiness and quarantine known-flaky tests

To measure flakiness, rerun each test 20 times on the same commit and count its failures. Keep the commit the same throughout those runs.

Use the audit script:

```sh
scripts/flake-scan.mjs --runs 20 --json
```

Follow this sequence:

1. Run each test 20 times on the same commit.
2. Count the failures for each test.
3. For a known-flaky test, use quarantine while it is fixed.
4. Assign an owner and a date to that quarantine.

Quarantine means moving a known-flaky test out of the required gate while it is fixed, with an owner and a date. Keep those details together: the test, its removal from the required gate, the owner, and the date.

Use the failure count to describe the repeated runs. Do not replace that count with the result of the final rerun. The measurement asks how many failures occurred in 20 runs on the same commit.

This lesson uses the author’s own rubric; it is not from a vendor. Its review questions are: Were failures counted across 20 runs on one commit? Does each quarantined test have an owner and a date?
