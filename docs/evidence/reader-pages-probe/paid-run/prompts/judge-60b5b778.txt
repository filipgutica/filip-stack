# See which process held a local TCP port

portlog records port history so you can answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Look back at port 3000

```sh
portlog start
portlog who 3000 --since 2h
```

Start the background recorder, then see every process that held port 3000 in the last two hours, newest first.

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Start the background recorder. |
| `portlog stop` | Stop the recorder. |
| `portlog who 3000` | Show every process that held port 3000, newest first. |
| `portlog who 3000 --since 2h` | Limit the history to the last two hours. |
| `portlog free 3000` | Stop the process that holds port 3000 now, after confirmation. |

## Keys

`-y` skips confirmation when you run `portlog free 3000`:

```sh
portlog free 3000 -y
```

## Good to know

**History**  
portlog keeps seven days of history in `~/.portlog/`.

**Command-line arguments**  
portlog never records command-line arguments because they can hold secrets.

**Recorder**  
On macOS, the recorder polls `lsof` every two seconds. On Linux, it reads `/proc/net/tcp`.

Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

brew install example/tap/portlog

```sh
portlog free 3000 -y
```

Stop the recorder:

```sh
portlog stop
```
