# Flaky tests and agents

## Measure failures before changing code

A flaky test fails sometimes without any code change. When an agent sees a red test, it tries to fix the code, even when the test is flaky. Before you act on that failure, measure how the test behaves on the same commit.

Start with the audit script:

```sh
scripts/flake-scan.mjs --runs 20 --json
```

Rerun each test 20 times on the same commit and count its failures. Keep the commit unchanged throughout the measurement. This gives you a failure count for each test under that condition.

The count answers a specific question: how many times did this test fail across those 20 runs? Keep that question separate from deciding what code to change. A test can fail while the code stays the same, so a red result alone does not establish that a code change caused it.

Use the full set of runs for the measurement. Stopping when a test turns green replaces the requested failure count with the outcome of one rerun.

## Quarantine known-flaky tests while fixing them

Agents tend to rerun tests until they pass, or to weaken an assertion. Both responses need attention when you review an agent’s work. Check whether it changed the code in response to a flaky failure, stopped after a green rerun, or weakened the assertion.

A required gate is a check that must pass. When that gate sometimes fails, it teaches agents and people to ignore it. The effect reaches beyond the individual red result: the required check becomes something people and agents learn to disregard.

Quarantine means moving a known-flaky test out of the required gate while it is fixed. Give the quarantined test an owner and a date. Keep these parts together:

- Identify the known-flaky test.
- Move it out of the required gate.
- Assign an owner.
- Set a date.

The owner and date are part of quarantine, alongside the move out of the gate. When you review that decision, check all three elements. A green rerun does not carry the same meaning as a test being fixed; flaky tests can pass without a code change.
