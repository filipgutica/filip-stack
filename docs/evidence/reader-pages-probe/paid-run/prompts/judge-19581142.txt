# portlog

## Find out what held a port—even after the process exits.

“What was on port 3000 an hour ago?”

portlog records which process held each local TCP port over time, so you can look it up later.

## Install

```sh
brew install example/tap/portlog
```

Runs on macOS and Linux.

## Usage

### Start recording

```sh
portlog start
```

Runs the recorder in the background. Stop it with:

```sh
portlog stop
```

### Look up a port’s history

```sh
portlog who 3000
```

See every recorded process that held port 3000, newest first—even processes that have exited.

Limit the results to the last two hours:

```sh
portlog who 3000 --since 2h
```

### Free a port

```sh
portlog free 3000
```

Stops the process holding port 3000 now, after confirmation. Add `-y` to skip confirmation.

## History and privacy

History is kept for 7 days in `~/.portlog/`.

portlog never records command-line arguments, because they can hold secrets.

## Built with Go. MIT licensed.

# See what held a port, even after it exits

portlog records which process held each local TCP port over time. Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Start recording

```sh
portlog start
portlog who 3000
```

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Runs a background recorder. |
| `portlog stop` | Stops the recorder. |
| `portlog who 3000` | Shows every process that held port 3000, newest first. |
| `portlog who 3000 --since 2h` | Limits the results to the last two hours. |
| `portlog free 3000` | Stops the process that holds port 3000 now, after confirmation. |
| `portlog free 3000 -y` | Stops the current process without confirmation. |

## Good to know

### History

portlog keeps history for 7 days in `~/.portlog/`.

### Command-line arguments

portlog never records command-line arguments, because they can hold secrets.
