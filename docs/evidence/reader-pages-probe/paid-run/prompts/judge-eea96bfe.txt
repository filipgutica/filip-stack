# See which process held a local TCP port

portlog records local TCP port history, so you can look back after a process exits.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

```sh
portlog who 3000
```

What was on port 3000 an hour ago?

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Run the background recorder. |
| `portlog stop` | Stop the recorder. |
| `portlog who 3000` | Show every process that held port 3000, newest first. |
| `portlog free 3000` | Stop the process holding port 3000 now, after confirmation. |

## Keys

| Option | What it does |
| --- | --- |
| `--since 2h` | Limit history to the last two hours: `portlog who 3000 --since 2h`. |
| `-y` | Skip confirmation: `portlog free 3000 -y`. |

## History

portlog keeps seven days of history in `~/.portlog/`.

## Good to know

**Command-line arguments**

portlog never records command-line arguments, because they can hold secrets.

# See which process held a port

portlog records which process held each local TCP port over time. Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

Start recording, then look up port 3000:

```sh
portlog start
portlog who 3000
```

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Runs a background recorder. |
| `portlog stop` | Stops the recorder. |
| `portlog who 3000` | Shows every process that held port 3000, newest first. |
| `portlog who 3000 --since 2h` | Limits the history to the last two hours. |
| `portlog free 3000` | Stops the process that holds port 3000 now, after confirmation. |

To skip the confirmation, use `portlog free 3000 -y`.

## Good to know

### History

portlog keeps history for 7 days in `~/.portlog/`.

### Command-line arguments

portlog never records command-line arguments, because they can hold secrets.
