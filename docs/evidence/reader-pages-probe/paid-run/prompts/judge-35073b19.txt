# portlog

## What was on port 3000 an hour ago?

portlog records which process held each local TCP port over time, so you can look it up after the process has exited.

## Install

```sh
brew install example/tap/portlog
```

Runs on macOS and Linux. Written in Go. MIT licensed.

## Start recording

```sh
portlog start
```

Runs a background recorder. History is kept for 7 days in `~/.portlog/`.

To stop recording:

```sh
portlog stop
```

## Look up a port

See every process that held port 3000, newest first:

```sh
portlog who 3000
```

Limit the results to the last two hours:

```sh
portlog who 3000 --since 2h
```

## Free a port

Stop the process holding port 3000 now, after confirmation:

```sh
portlog free 3000
```

Skip the confirmation with `-y`:

```sh
portlog free 3000 -y
```

## What gets recorded

portlog records local TCP port ownership. It never records command-line arguments, because they can hold secrets.

# See which process held a port

portlog records which process held each local TCP port over time. Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

Start recording, then look up port 3000:

```sh
portlog start
portlog who 3000
```

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Runs a background recorder. |
| `portlog stop` | Stops the recorder. |
| `portlog who 3000` | Shows every recorded process that held port 3000, newest first. |
| `portlog who 3000 --since 2h` | Limits the results to the last two hours. |
| `portlog free 3000` | Stops the process that holds port 3000 now, after confirmation. |
| `portlog free 3000 -y` | Skips confirmation when stopping the current process. |

## Good to know

### History

portlog keeps history for 7 days in `~/.portlog/`.

### Command-line arguments

portlog never records command-line arguments because they can hold secrets.
