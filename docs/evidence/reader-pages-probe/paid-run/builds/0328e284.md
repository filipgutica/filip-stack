# portlog

## Find out what held a port—even after the process exits.

“What was on port 3000 an hour ago?”

portlog records which process held each local TCP port over time, so you can look it up later.

## Install

```sh
brew install example/tap/portlog
```

Runs on macOS and Linux.

## Usage

### Start recording

```sh
portlog start
```

Runs the recorder in the background. Stop it with:

```sh
portlog stop
```

### Look up a port’s history

```sh
portlog who 3000
```

See every recorded process that held port 3000, newest first—even processes that have exited.

Limit the results to the last two hours:

```sh
portlog who 3000 --since 2h
```

### Free a port

```sh
portlog free 3000
```

Stops the process holding port 3000 now, after confirmation. Add `-y` to skip confirmation.

## History and privacy

History is kept for 7 days in `~/.portlog/`.

portlog never records command-line arguments, because they can hold secrets.
