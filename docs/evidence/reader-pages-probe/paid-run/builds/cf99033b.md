# portlog

## What was on port 3000 an hour ago?

portlog records which process held each local TCP port over time, so you can look it up after the process has exited.

## Install

```sh
brew install example/tap/portlog
```

Runs on macOS and Linux.

## Record port history

Start the background recorder:

```sh
portlog start
```

Stop it:

```sh
portlog stop
```

## Look up a port

See every process that held port 3000, newest first:

```sh
portlog who 3000
```

Limit the results to the last two hours:

```sh
portlog who 3000 --since 2h
```

## Free a port

Stop the process holding port 3000 now, after confirmation:

```sh
portlog free 3000
```

Skip confirmation with `-y`:

```sh
portlog free 3000 -y
```

## History and privacy

History is kept for 7 days in `~/.portlog/`.

portlog never records command-line arguments, because they can hold secrets.
