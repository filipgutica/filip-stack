# See which process held a local TCP port

portlog records port ownership over time, so you can look it up after a process exits.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Look back at a port

“What was on port 3000 an hour ago?”

```sh
portlog who 3000
```

See every recorded process that held port 3000, newest first.

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Start the background recorder. |
| `portlog stop` | Stop the recorder. |
| `portlog who 3000 --since 2h` | Limit port 3000’s history to the last two hours. |
| `portlog free 3000` | Stop the process holding port 3000 now, after confirmation. |

Use `portlog free 3000 -y` to skip confirmation.

## Good to know

**History**  
Records stay in `~/.portlog/` for 7 days.

**Command-line arguments**  
portlog never records command-line arguments, because they can hold secrets.
