# release-notes

## What it does

Drafts release notes from merged PRs between two tags. `release-notes` gathers the PRs and drafts the notes; `technical-writing` edits prose.

## When to use it

Use it when you want a release-notes draft for a tag range. It runs only when invoked manually:

```text
/release-notes <from-tag> <to-tag>
```

Both tags must exist, and `gh` must be signed in. The skill stops before drafting if either tag is missing or `gh auth status` fails.

## How it works

It groups PRs by Conventional Commit type, with features, fixes, and breaking changes first. PRs labeled `skip-notes` are excluded.

Each breaking change needs a migration line. If the PR body has none, the draft marks it `TODO: migration`.

## What you get

A `RELEASE_NOTES.md` file in the working tree. The skill writes the draft and stops. It never publishes.
