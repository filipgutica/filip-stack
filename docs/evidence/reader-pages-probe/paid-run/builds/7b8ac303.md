# release-notes

## What it does

`release-notes` drafts release notes from merged PRs between two tags.

## When to use it

Use it to gather PRs and prepare a release draft. Use `technical-writing` when you need to edit prose.

The skill runs only when you invoke it manually:

```text
/release-notes <from-tag> <to-tag>
```

## How it works

`gh` must be signed in. The skill stops if `gh auth status` fails. If either tag does not exist, it stops before drafting.

It skips PRs labeled `skip-notes` and groups the rest by Conventional Commit type, with features, fixes, and breaking changes first. If a PR has labels for several types, it uses the type named by most labels. Ties follow label order.

## What you get

The skill writes `RELEASE_NOTES.md` in the working tree and stops. It never publishes.

Each breaking change needs a migration line. If the PR body has none, the draft marks it `TODO: migration`.
