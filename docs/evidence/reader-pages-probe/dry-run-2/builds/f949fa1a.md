# portlog

Know what was on that port.

portlog records which process held each local TCP port over time. Answer “what was on port 3000 an hour ago?” even after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Start recording

Run the recorder in the background:

```sh
portlog start
```

Stop it when you’re done:

```sh
portlog stop
```

## Look back

See every process that held port 3000, newest first:

```sh
portlog who 3000
```

Limit the results to the last two hours:

```sh
portlog who 3000 --since 2h
```

## Free a port

Stop the process holding port 3000 now. portlog asks for confirmation first.

```sh
portlog free 3000
```

Skip confirmation with `-y`:

```sh
portlog free 3000 -y
```

## Keep history, leave out secrets

History stays in `~/.portlog/` for 7 days. portlog never records command-line arguments, because they can hold secrets.
