# See which process held a port

portlog records which process held each local TCP port over time. Use it to answer “what was on port 3000 an hour ago?” after the process has exited.

```sh
brew install example/tap/portlog
```

macOS and Linux · Written in Go · MIT license

## Try it

Start the recorder, then check port 3000:

```sh
portlog start
portlog who 3000
```

## Commands

| Command | What it does |
| --- | --- |
| `portlog start` | Runs a background recorder. |
| `portlog stop` | Stops the recorder. |
| `portlog who 3000` | Shows every recorded process that held port 3000, newest first. |
| `portlog free 3000` | Stops the process that holds port 3000 now, after confirmation. |

## Keys

Use `--since 2h` to limit a history query to the last two hours:

```sh
portlog who 3000 --since 2h
```

Use `-y` to skip confirmation when stopping the current process:

```sh
portlog free 3000 -y
```

## History and privacy

portlog keeps history for 7 days in `~/.portlog/`.

It never records command-line arguments, because they can hold secrets.

## Good to know

<dl>
<dt>Recorder</dt>
<dd>The recorder polls <code>lsof</code> every 2 seconds on macOS and reads <code>/proc/net/tcp</code> on Linux.</dd>

<dt>Storage</dt>
<dd>The store is SQLite in WAL mode, with a busy timeout of 500 ms.</dd>

<dt>History queries</dt>
<dd>The <code>who</code> query uses the index <code>idx_port_time</code>.</dd>

<dt>Releases</dt>
<dd>Releases use release-please, and <code>fix:</code> makes a patch.</dd>
</dl>
