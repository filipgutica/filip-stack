# Inspect ZIP archives before you unpack them

sackview shows each entry’s name, compressed size, and unpacked size.

```sh
pipx install sackview
```

ZIP archives only · Offline inspection · No extraction

## Capture

```sh
sackview inspect photos.zip
```

Lists the archive’s entries.

## Commands

| Command | What it shows |
| --- | --- |
| `sackview inspect photos.zip` | All entries in the archive. |
| `sackview inspect photos.zip --largest 10` | The ten entries with the largest unpacked sizes, largest first. |
| `sackview inspect photos.zip --find '*.csv'` | Only entries whose names match the pattern. |

## Keys

No key bindings are specified.

## Check disk space

sackview displays the total unpacked size. Use it to check available disk space before extracting the archive elsewhere.

## Good to know

**Archive safety**  
sackview never extracts entries or changes the archive.

**Privacy**  
Inspection sends no archive contents to a service.

**Unsupported formats**  
Other archive formats produce an unsupported-format message and exit code `24`.
