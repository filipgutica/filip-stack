## What it does

`term-weave` is a skill that drafts a glossary of project terms from documents in a folder you supply.

## When to use it

Use it when project vocabulary is scattered across documents or newcomers encounter unexplained terms.

## How it works

Run it manually with `/term-weave <source-folder>`.

Illustrative example:

```text
/term-weave ./project-docs
```

It reads Markdown and plain-text documents and ignores other file types. If the folder is missing or contains no readable supported documents, it stops and explains the problem without drafting.

Every drafted definition links to the passage that supports it. The skill does not invent definitions. Terms without a supporting explanation appear under **Unresolved terms**.

If sources give conflicting definitions, it preserves both in one entry, links each source, and marks the entry **Conflict**.

## What you get

The skill writes `GLOSSARY.md` in your working directory. It sorts defined entries alphabetically and places **Unresolved terms** after them. It never changes the source documents.
