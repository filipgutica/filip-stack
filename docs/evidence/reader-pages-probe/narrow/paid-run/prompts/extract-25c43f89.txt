# Renaming rooms in the Kestrel directory

## Try a rename with a saved link

Kestrel is a fictional directory of shared work rooms, each with a room key and a human-readable display name. Room owners can change the display name. When a room needs a different label, a rename lets the owner change what people see.

Start by checking that a saved room link still works after the change:

1. Save a link that identifies the room by its room key.
2. Rename the room.
3. Open the saved link.
4. Confirm that it reaches the same room and shows the new display name.

For an illustrative example, an owner could rename a room from “Planning” to “Project planning.” Save its room link before making that change. When you open the saved link afterward, the expected result is the original room with “Project planning” displayed.

Check both parts of that result. Reaching the same room verifies that the saved link still identifies it. Seeing the new name verifies that Kestrel displays the changed label when the link opens.

## Understand what the link identifies

A room key is assigned when the room is created. It never changes, and Kestrel never reuses it for another room. This gives the room an identity that remains the same through a rename.

The display name is the label people see. Because owners can change that label, it can differ between two visits to the same room. A new name does not change the room key.

When someone opens a saved room link, Kestrel looks up the key and displays the room’s current name. The link therefore continues to identify the room even when its visible label changes.

A link built from a display name can stop finding the room after a rename. Its name has changed, so the name used to build that link may no longer find it. Use the room key when building a room link.

In the storage schema, `room_ref` is the key column and `title_text` is the display-name column. When working with these columns, keep their roles clear: `room_ref` holds the room’s permanent key, while `title_text` holds the label an owner can change.
