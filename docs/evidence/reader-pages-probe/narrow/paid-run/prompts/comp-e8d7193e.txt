# Renaming rooms in the Kestrel directory

## 1. Identify the room by its key

When you rename a room in Kestrel, change its display name and keep its room key. Saved links use the key to reach the same room after the rename.

Kestrel is a fictional directory of shared work rooms. Each room has two distinct values:

- A **room key** identifies the room. Kestrel assigns it when the room is created. The key never changes or gets reused for another room.
- A **display name** is the human-readable label people see. Room owners can change this label.

This distinction determines how a saved link works. When someone opens a room link, Kestrel looks up the key and displays the room’s current name. The link can therefore show a different name after a rename while still reaching the same room.

A link built from a display name can stop finding the room after a rename because that name has changed. Use the room key when identifying the room in a saved link.

In the storage schema, `room_ref` is the key column and `title_text` is the display-name column. Read these identifiers according to their roles: `room_ref` holds the room’s identity, and `title_text` holds its changeable label.

## 2. Verify the rename with a saved link

Save a room link before the rename so you can check it afterward. The expected result has two parts: the link reaches the same room, and the room shows its new display name.

Follow this sequence:

1. Before renaming the room, save its room link.
2. Rename the room as its owner.
3. Open the link you saved before the rename.
4. Check that it reaches the same room.
5. Check that the room displays the new name.

Use the previously saved link for this check. Opening it exercises the lookup by the room’s unchanged key and the display of its current name.

Check both results. Reaching the same room verifies that the saved link still identifies it. Seeing the new display name verifies that Kestrel presents the renamed label when that link opens. Together, these observations verify the rename’s expected behavior.
