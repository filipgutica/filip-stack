# Renaming rooms in the Kestrel directory

## 1. Identify the room by its key

Use the room key when you build a room link. Use the display name as the label people see.

Kestrel is a fictional directory of shared work rooms. Each room has a room key and a display name. Kestrel assigns the key when it creates the room. That key never changes, and Kestrel never reuses it for another room.

The display name is the room’s human-readable label. Room owners can change it. A rename therefore changes what people see while the room keeps its assigned key.

When you work with the storage schema, these concepts have different column names:

| Concept | Storage column | Behavior |
| --- | --- | --- |
| Room key | `room_ref` | Never changes or gets reused |
| Display name | `title_text` | Room owners can change it |

Saved links identify rooms by their keys. When someone opens a saved link, Kestrel looks up the key and displays the room’s current name. The saved link can therefore reach the room after its display name changes.

A link built from a display name can stop finding the room after a rename because that name has changed. Keep this distinction in mind when you choose the value that identifies a room in a link.

## 2. Verify a rename with a saved link

Save a room link before you rename the room. This gives you a link from before the change to open afterward.

Follow these steps:

1. Open the room you intend to rename.
2. Save its room link.
3. Rename the room as its owner.
4. Open the link you saved before the rename.
5. Confirm that it reaches the same room.
6. Confirm that the room shows its new display name.

Check both results. Reaching the same room verifies that the saved link still identifies it. Seeing the new name verifies that Kestrel displays the current label when the link opens.

Use the previously saved link for this check. A link saved only after the rename does not verify what happens to a link saved beforehand.
