# Renaming rooms in the Kestrel directory

## 1. Keep the room key separate from its display name

When you rename a room in Kestrel, change its display name. The room key stays the same.

Kestrel is a fictional directory of shared work rooms. Each room has a key and a display name, with different roles:

| Field | Purpose | Rename behavior |
| --- | --- | --- |
| Room key | Identifies the room | Never changes |
| Display name | Provides the human-readable label people see | Room owners can change it |

Kestrel assigns the key when it creates the room. That key never gets reused for another room. A changed display name therefore does not give the room a new identity.

For engineers working with storage, the schema uses these column names:

- `room_ref` stores the room key.
- `title_text` stores the display name.

Use this distinction when reading rename behavior in the schema: `title_text` is the label that can change; `room_ref` identifies the room.

Saved links identify rooms by their keys. When someone opens a saved link, Kestrel looks up its key and displays the room’s current name. The link can therefore reach the same room after its owner changes the display name.

A link built from a display name can stop finding the room after a rename. Its name has changed, so the old name might no longer find it.

## 2. Verify the rename with a saved link

Save a room link before you rename the room. This gives you a link from before the change to check afterward.

1. Open the room and save its room link.
2. Rename the room as its owner.
3. Open the saved link.
4. Confirm that it reaches the same room.
5. Confirm that the room shows the new display name.

Check both results. Reaching the same room verifies that the saved link still identifies it after the rename. Seeing the new display name verifies that Kestrel displays the current label.

Opening a link only after the rename does not perform this before-and-after check. Use the link you saved beforehand to verify the connection between the unchanged room identity and its changed name.
