# See what is inside a ZIP before you unpack it

sackview lists archive entries and their sizes so you can check the contents before extracting elsewhere.

```sh
pipx install sackview
```

ZIP archives only · Offline inspection · No extraction or archive changes

## Inspect an archive

```sh
sackview inspect photos.zip
```

Each entry shows its name, compressed size, and unpacked size.

## Commands

| Command | What it shows |
| --- | --- |
| `sackview inspect photos.zip` | All entries in the archive |
| `sackview inspect photos.zip --largest 10` | The ten entries with the largest unpacked sizes, largest first |
| `sackview inspect photos.zip --find '*.csv'` | Only entries whose names match the pattern |

## Keys

Key bindings are not specified.

## Check disk space before extracting

sackview displays the total unpacked size. Use this total to check available disk space before extracting elsewhere.

## Good to know

ZIP support
: Other archive formats produce an unsupported-format message and return exit code 24.

Archive protection
: sackview never extracts entries or changes the archive.

Offline inspection
: Inspection works offline and sends no archive contents to a service.
