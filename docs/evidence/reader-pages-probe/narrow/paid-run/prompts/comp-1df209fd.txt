# term-weave

## What it does

`term-weave` drafts a glossary of project terms from documents in a supplied folder. Every drafted definition links to the passage that supports it.

## When to use it

Use it when project vocabulary is scattered across documents or newcomers encounter unexplained terms.

## How it works

Run the skill manually:

```text
/term-weave <source-folder>
```

It reads Markdown and plain-text documents in the supplied folder and ignores other file types.

If the folder is missing or contains no readable supported documents, it stops and explains the problem without drafting.

The skill does not invent definitions. It lists terms without a supporting explanation under **Unresolved terms**.

If sources give conflicting definitions, it preserves both in one entry, links each source, and marks the entry **Conflict**.

## What you get

The skill writes `GLOSSARY.md` in the working directory. Entries appear alphabetically, with **Unresolved terms** after the defined entries.

The source documents remain unchanged.
