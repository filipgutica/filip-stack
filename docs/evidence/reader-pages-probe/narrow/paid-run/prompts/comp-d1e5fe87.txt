## What it does

`term-weave` drafts a glossary of project terms from documents in a folder you supply.

## When to use it

Use it when project vocabulary is scattered across documents or newcomers encounter unexplained terms.

## How it works

Run the skill manually with `/term-weave <source-folder>`.

For example, if your documents are in `./project-docs`, run:

```text
/term-weave ./project-docs
```

It reads Markdown and plain-text documents and ignores other file types. It never changes the source documents.

If the folder is missing or contains no readable supported documents, it stops and explains the problem without drafting.

## What you get

The skill writes `GLOSSARY.md` in the working directory, with glossary entries sorted alphabetically.

Every drafted definition includes a link to the passage that supports it. The skill does not invent definitions. Terms without a supporting explanation appear under **Unresolved terms**, after the defined entries.

If sources give conflicting definitions, the skill preserves both definitions in one entry, links each source, and marks the entry **Conflict**.
