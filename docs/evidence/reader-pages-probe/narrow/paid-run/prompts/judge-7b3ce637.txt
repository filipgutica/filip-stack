# See inside a ZIP before unpacking

sackview shows what is inside a ZIP archive before you unpack it. Check the total unpacked size against available disk space before extracting elsewhere.

```sh
pipx install sackview
```

Inspection works offline and sends no archive contents to a service.

## Inspect an archive

```sh
sackview inspect photos.zip
```

Each entry shows its name, compressed size, and unpacked size.

## Commands

Show the ten entries with the largest unpacked sizes, largest first:

```sh
sackview inspect photos.zip --largest 10
```

Show only entries whose names match a pattern:

```sh
sackview inspect photos.zip --find '*.csv'
```

## Good to know

### Archive safety

sackview never extracts entries or changes the archive.

### Supported formats

sackview supports ZIP archives only. Other archive formats produce an unsupported-format message and return exit code 24.

# sackview

See what’s inside a ZIP archive before you unpack it. Each entry shows its name, compressed size, and unpacked size.

```sh
pipx install sackview
```

## Inspect an archive

List the archive’s entries and check the total unpacked size against your available disk space before extracting elsewhere.

```sh
sackview inspect photos.zip
```

```sh
sackview inspect photos.zip --find '*.csv'
```

## Your archive stays unchanged

sackview never extracts entries or changes the archive. Inspection works offline and sends no archive contents to a service.

## Supported format

sackview supports ZIP archives only. Other archive formats produce an unsupported-format message and return exit code `24`.
