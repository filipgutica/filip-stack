# See inside a ZIP archive with sackview

Check archive entries and sizes before you unpack them.

```sh
pipx install sackview
```

ZIP archives only · Offline inspection · No archive changes

## Inspect an archive

```sh
sackview inspect photos.zip
```

Each entry shows its name, compressed size, and unpacked size.

## Commands

### List entries

```sh
sackview inspect photos.zip
```

### Find the largest entries

Show the ten entries with the largest unpacked sizes, largest first:

```sh
sackview inspect photos.zip --largest 10
```

### Filter by name

Show only entries whose names match the pattern:

```sh
sackview inspect photos.zip --find '*.csv'
```

## Keys

Keyboard shortcuts are not specified.

## Check disk space before extracting

sackview displays the total unpacked size. Use this total to check available disk space before extracting elsewhere.

## Good to know

- **Archive contents:** sackview never extracts entries or changes the archive.
- **Privacy:** inspection works offline and sends no archive contents to a service.
- **Supported formats:** sackview supports ZIP archives only. Other formats produce an unsupported-format message and return exit code `24`.
