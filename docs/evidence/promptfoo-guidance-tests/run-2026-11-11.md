## Free parity check

Before any paid call, the old and new harnesses ran against the same local OpenAI-compatible stub. The stub answered from a hash of each prompt, so identical prompts got identical answers and the base and working tree diverged.

- `eval:autonomy --base 3611d573` and `eval:delegation --base 6f470ef0`: every table row, total, and gate count matched the old harness.
- `eval:routing --base 94ca3444~1`, both models: every row the old harness printed matched; the rest passed every attempt in both harnesses, and both reported the same four regressions.
- promptfoo sends the same request body as the old harness: only `model` and `messages`.

## Results storage

Each run is saved in promptfoo's local results store and opens with `pnpm eval:view`. The JSON export of the paid autonomy run was 2.8 MB for 108 calls: each call carries about 17,800 characters of rendered guidance, plus the reply, and the export contains local home-directory paths. The runner therefore does not write runs to `docs/evidence/`; a study copies the printed tables, as this file does.
