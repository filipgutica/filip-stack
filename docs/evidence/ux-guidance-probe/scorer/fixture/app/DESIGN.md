# Acme Console design system

Acme Console is a web console for developers. Its look comes from this file and `tokens.css`.

- Colors, font sizes, spaces, radii, and the motion duration are tokens in `tokens.css`.
- The app follows the system light or dark theme through `prefers-color-scheme`.
- Shared components are in `app.css`: `.card`, `.btn`, `.btn-primary`, `.field` (with `.hint` and `.error`), `.notice-error`, and `.notice-success`.
