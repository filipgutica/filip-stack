Components

Every component in the design language, in each state that applies. The styles use only tokens.css, and the markup carries the roles and states a React or Vue version should copy. Component specs describe each one; decisions say why.

The first specimen in each row is live. The others pin one state for display and do not respond. Use the theme control to compare light and dark.

Core

A new project adopts these as they are, with its own hue and fonts set in the tokens.css identity block.
