A smaller set of design decisions.

Keep navigation, examples, and reference text in a balanced frame. The content stays left aligned and the first useful step is easy to find.

Illustrative setup command

npm install @example/ui

Let the structure do the work

Use readable prose and clear section boundaries. Examples can use the full article width without stretching every paragraph.

Frame
The navigation and article are centered together.
Measure
Running text has a comfortable reading width.
Evidence
Commands, examples, and caveats stay near the task.

Keep the useful paths intact

Native links work without JavaScript. Focus stays visible, wide code scrolls within its container, and the page follows the system appearance without an extra theme control.
