Color

Ratios are WCAG contrast against each named background: 4.5:1 for text, and 3:1 for icons, marks, and control edges. A ratio below its target says so in text.

Focus and motion

  • 2px solid --accent, offset 2pxControls that act or set a value, quiet actions included: one ring with no glow, over their own raise or sink shadow, the same width as the link and navigation outline. Pointer hover never draws focus.
  • --field-focus, --shadow-raise, accent edge at 35%Fields lift out of their well instead of drawing a ring. A transparent 2px outline keeps a ring in forced colors. The cue is below 3:1 by choice.
  • 2px solid --focus, offset 2pxLinks, navigation rows, and tabs keep the base outline.
    Documentation example
  • offset -2pxOnly inside a scrolling or clipping parent, or a segmented control, with a comment that names the reason
